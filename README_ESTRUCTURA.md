# Estructura actual de SimuliMath (Tkinter)

- sim/: Módulos de simulación y utilidades
- config/: Configuración y parámetros
- results/: Resultados y gráficos
- tests/: Pruebas automáticas
- bin/: Scripts de experimentos
- simulimath_gui.py: Interfaz gráfica Tkinter

## Fase 0: Preparación y alcance

- Modulaciones mínimas: BPSK (obligatoria), QPSK (opcional)
- Interferencias: CW, pulsed, broadband, sweep
- Métricas: SNR, BER, PER
- Archivo de parámetros: config/params.json
